# KB: 다이어그램 가독성 규약

> 사용자의 1순위 요구는 **가독성**이다. 정확하지만 읽기 어려운 다이어그램은 실패다.
> 이 규약은 모든 산출의 **최종 점검 체크리스트**다.

## 리뷰 훅 (이걸 점검하라 — 산출 직전 필수)
- [ ] 노드 수가 **예산 내**인가(권장 ≤ 20, 상한 25). 넘으면 분리했는가.
- [ ] 노드 라벨이 **평이한 한국어 동작 설명**인가(함수 시그니처 원문을 박지 않음 — 그건 앵커가 가리킴).
- [ ] 방향(`TD`/`LR`)을 하나로 고정했는가. 엣지가 서로 교차해 얽히지 않는가.
- [ ] 단계가 3개 이상이면 `subgraph`로 묶었는가.
- [ ] 분기 엣지에 **실제 조건** 라벨이 있는가. 라벨이 너무 길지 않은가(한 줄로 요약).
- [ ] 색·스타일을 **의미가 있을 때만** 절제해서 썼는가(장식용 남발 금지).
- [ ] **모든 노드 → `파일:라인` 앵커 범례**가 1:1로 있는가(사용자 핵심 요구). 누락 노드 없는가.
- [ ] 경로가 레포 루트 기준 상대경로인가.

## 규칙

### 1. 노드 수 예산 — 한 화면에 읽히게
- 한 다이어그램 **권장 ≤ 20 노드, 상한 25**. 사람은 그 이상을 한눈에 못 읽는다.
- 트리비얼 단계(단순 getter·로깅·1:1 매핑)는 부모 노드에 **흡수**한다.
- 넘으면 **2단 구성**: ① 상위 단계 다이어그램(phase 5~7개) → ② 각 phase의 상세 다이어그램. 상위 노드 라벨과 하위 다이어그램 제목을 맞춘다.

### 2. 라벨 — 무엇을 하는가(what), 어떻게(how)는 앵커로
- 좋은 라벨: "재고 검증", "주문 저장", "결제 요청 (외부)".
- 나쁜 라벨: `validateStock(orderId: Long, qty: Int): Boolean` (시그니처 원문) — 이건 앵커가 가리킨다.
- 라벨은 한 줄. 길면 명사구로 줄이고 세부는 노트/범례 설명 칼럼으로 보낸다.

### 3. 방향과 흐름 — 시선이 한 방향으로
- 흐름이 길고 분기 많음 → `TD`. 단계가 적고 좌→우 파이프라인 → `LR`.
- 되돌아오는 엣지(루프)는 라벨로 의도를 밝힌다. 교차를 줄이려 노드 순서를 조정한다.

### 4. 그룹화 — subgraph로 단계를 묶기
- "입력 검증 / 핵심 처리 / 외부 연동 / 응답" 같은 **phase**로 묶으면 큰 그림이 먼저 읽힌다.
- 그룹 제목은 명사구. 그룹 간 엣지는 그룹 밖에서 연결한다.

### 5. 색·스타일 — 의미가 있을 때만
- 예외/실패 경로만 점선(`-.->`)이나 한 가지 강조색으로. 정상 경로는 기본 스타일.
- `classDef`로 "외부 시스템", "에러" 같은 **의미 단위**에만 색을 준다. 무지개 금지.
```
classDef ext fill:#fde,stroke:#c39;
classDef err fill:#fee,stroke:#e55;
class N5 ext
class N4 err
```

### 6. 앵커 범례 — 코드로 바로 이동 (하우스 포맷 · 필수)
다이어그램 **바로 아래**에 노드↔코드 위치 표를 둔다. 터미널에서 `파일:라인`은 클릭하면 그 라인으로 이동한다.

```markdown
| 노드 | 코드 위치 (클릭하여 이동) | 설명 |
|------|--------------------------|------|
| N1 | `src/order/OrderController.kt:42` | 주문 생성 요청 진입점 |
| N2 | `src/order/OrderService.kt:88` | 재고 수량 검증 분기 |
```
- 행 순서 = 노드 ID 순(결정론). 경로는 상대경로, 백틱으로 감싼다(클릭 인식).
- 동적 디스패치로 대상이 불확실하면 호출부를 앵커하고 설명에 "(추정: 구현 런타임 결정)"을 단다.

### 7. 산출 3단 구조 (항상 이 순서)
1. **다이어그램** (Mermaid)
2. **앵커 범례표** (노드 → `파일:라인`)
3. **노트** (추정/경계/미해결)

## 인용 시
"가독성 규약상 노드 25개 초과 → 상위 phase 다이어그램 + 하위 상세로 분리. 모든 노드는 앵커 범례에 `파일:라인` 대응" 식으로 근거를 단다.
