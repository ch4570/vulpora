# KB: 테스트 설계 기법

ISTQB Foundation 신택스의 블랙박스(명세 기반) 기법. 각 기법은 **전수 테스트 불가능**을 전제로,
적은 케이스로 결함을 많이 드러내도록 입력을 선택하는 방법이다.

## 1. 동등분할 (Equivalence Partitioning, EP)
- 입력(또는 출력) 도메인을 **같은 처리를 받는 그룹(파티션)** 으로 나누고, 각 파티션에서 **대표값 1개**만 테스트.
- 파티션은 **유효(valid) + 무효(invalid)** 모두 도출한다. 무효 파티션은 한 번에 하나씩만 위반(여러 무효를 한 케이스에 섞으면 어느 검증이 걸렸는지 모름).
- 예시(일반 엔티티 `Member.age`, 규칙: 19~120 허용):
  | 파티션 | 종류 | 대표값 |
  |---|---|---|
  | age < 19 | 무효 | 10 |
  | 19 ≤ age ≤ 120 | 유효 | 30 |
  | age > 120 | 무효 | 130 |
  | 비정수/음수 | 무효 | -1, "abc" |

## 2. 경계값 분석 (Boundary Value Analysis, BVA)
- 결함은 **파티션 경계**에 집중된다 → 경계 양쪽을 표본.
- 2-value: 경계와 그 바로 바깥. 3-value: 경계−1, 경계, 경계+1.
- 위 `age`(19~120) 3-value 경계: **18, 19, 20** 그리고 **119, 120, 121**.
- 문자열 길이/배열 크기/페이지 size 등 "범위가 있는 모든 입력"에 적용. 예: `Order.quantity ∈ [1, 99]` → 0,1,2 / 98,99,100.

## 3. 결정표 (Decision Table)
- **여러 조건의 조합**이 결과를 가르는 비즈니스 규칙에 사용. 조건(행) × 규칙(열) 행렬로 **누락 조합**을 드러낸다.
- 예시(일반 엔티티 — `Order` 무료배송 규칙: 회원등급 VIP, 금액 ≥ 50000):
  | 조건 | R1 | R2 | R3 | R4 |
  |---|---|---|---|---|
  | VIP 회원? | Y | Y | N | N |
  | 금액 ≥ 50000? | Y | N | Y | N |
  | **결과: 무료배송** | O | O | O | X |
- 조건 N개 → 최대 2^N 규칙. 영향 없는 조건은 `—`(무관)로 묶어 규칙 수를 줄인다.

## 4. 상태 전이 (State Transition)
- **상태를 갖는 객체**(예: `Order.status`)의 전이 규칙을 검증. 유효 전이 + **무효 전이**(허용 안 된 전이 시도)까지.
- 예시 상태: `CREATED → PAID → SHIPPED → DELIVERED`, 어느 단계든 `CANCELED` 가능(단 `DELIVERED`에서는 불가).
  | 현재 | 이벤트 | 기대 |
  |---|---|---|
  | CREATED | pay | PAID (유효) |
  | DELIVERED | cancel | 거부/예외 (무효 전이) |
  | SHIPPED | pay | 거부 (무효 전이) |
- 0-switch(단일 전이)부터, 필요하면 1-switch(연속 2전이)로 커버리지를 높인다.

## 5. 페어와이즈 (Pairwise / All-pairs)
- 다수 파라미터의 **조합 폭증**을 줄인다. 대부분의 결함은 **1~2개 인자의 상호작용**에서 발생 → 모든 **2개 파라미터 값 쌍**이 적어도 한 번 등장하도록 조합.
- 예시(3 파라미터): `결제수단{카드,계좌} × 배송{일반,당일} × 회원{일반,VIP}` = 전수 8 → pairwise 4~5개로 압축.
- 전수가 비현실적인 설정/조합 테스트(폼 옵션, 피처 플래그 매트릭스)에 적합. 단 **안전 핵심 조합**은 페어와이즈로 빠질 수 있으니 별도 명시.

## 적용 순서 (권장)
1. 입력마다 EP로 파티션 → 2. 각 파티션 경계에 BVA → 3. 조건 조합 규칙은 결정표 → 4. 상태 객체는 상태전이 → 5. 다파라미터 조합은 페어와이즈.

## 리뷰 훅
- [ ] 모든 입력에 대해 **유효·무효 파티션**이 모두 도출되었는가(EP).
- [ ] 범위형 입력의 **경계값**(min±1, max±1)이 케이스에 있는가(BVA).
- [ ] 조건이 2개 이상 결합되는 규칙을 **결정표**로 전개해 누락 조합이 없는가.
- [ ] 상태 객체에 **무효 전이** 케이스가 있는가(유효 전이만 있으면 불완전).
- [ ] 다파라미터 조합을 전수로 폭증시키지 않고 **페어와이즈**로 줄였는가(+ 안전 핵심 조합 별도 보강).
- [ ] 각 케이스에 **어떤 기법으로 이 값을 골랐는지** 근거가 적혀 있는가.
