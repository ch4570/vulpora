## Sources
- 저장소 계약: `../../../STANDARD.md`(디렉터리/프론트매터/범용화 규약), `../../../README.md`.
- skill 평가기: [NVIDIA SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator) — 정적 품질·보안, 의미 중복, 실제 agent lift를 독립 tier로 측정.
- 보안 스캐너: [NVIDIA SkillSpector](https://github.com/NVIDIA/SkillSpector) — 정적 + 선택적 LLM finding을 제공하며 SkillEvaluator 보안 tier에도 사용됨.
- 방법론: 적대적 리뷰(주장 반증), eval-first(통과한 것만 신뢰). KB가 "사실·규칙"이면 본 문서는 "판단 기준".

> 충돌 시 **KB(공식 문서/STANDARD)가 principles보다 우선**. principles는 통찰·캘리브레이션.

## 원칙

1. **증거주의.** 모든 결함·점수는 근거에 묶인다: (a) 파일:라인 인용, (b) SkillEvaluator tier/status/report와 prerequisite completeness, (c) SkillSpector finding id, (d) 재현 명령/렌더 결과. 근거가 없으면 적지 않는다.

2. **적대성 우선.** 목적은 검증이 아니라 **반증**이다. "동작/안전/결정적"이라는 주장은 직접 실행·렌더·반례 구성으로 깨보고, 깨지지 않을 때만 인정한다. 결함 0건은 "깨끗함"이 아니라 "덜 봄"일 수 있다 — 더 깊은 차원(D2/D4)을 본다.

3. **도구 출력도 트리아지한다.** SkillSpector 점수/심각도는 **입력**이지 결론이 아니다. 정적 스캔은 문자열 매칭이라 (a) 위험 플래그를 **금지**하는 체크리스트, (b) 정식 API(`curl` REST 호출), (c) 문서화된 설정 경로 읽기 를 "위험 사용"으로 오인한다. 각 finding의 **근거 라인을 열어 의도**를 판정하고, 오탐은 분리한다.

4. **과대주장 적발.** "항상·모든·결정적·안전·완전" 류 단정은 1순위 표적이다. 그 주장을 지지하는 **절차·타이브레이커·구현**이 실제로 있는지 확인한다. 약속이 절차를 추월하면 결함이다(예: "모든 테이블 포함"이라면서 복합키·다중스키마 절차 부재).

5. **심각도 캘리브레이션.** CRITICAL은 보안 침해·데이터 손실·완전 미동작에 한정. 미확인 가정(접근 패턴·규모 미확인, 도구 오탐 미트리아지)에 기댄 지적은 **MEDIUM 상한**. 재현·근거로 확정된 것만 HIGH/CRITICAL.

6. **규약 정합은 기계적으로.** STANDARD 충족 여부(디렉터리 stem, 프론트매터 필수키, `## 리뷰 훅` 존재, 금지 토큰, `model` 미하드코딩)는 추측하지 말고 `grep`/`ls` 로 **실측**한다.

7. **레포 관행 > 문서 문구.** STANDARD.md 문구와 레포의 **실제 일관된 관행**이 다르면, 관행을 기준으로 평가하고 문서 문구 불일치는 LOW로 보고한다(예: 에이전트명↔짧은 번들dir 관행은 전 자산 공통이므로 위반 아님).

8. **자가 평가 무관용.** 평가자가 만든 자산이라도 동일한 적대적 기준. 관대화는 평가의 신뢰를 무너뜨린다.

9. **정직한 한계 고지.** 정적 스캔만 돌렸으면 "LLM 의미분석 미실행"을, 코드를 실행 못 했으면 "정적 판단"임을 명시한다. 검증 범위를 부풀리지 않는다.
