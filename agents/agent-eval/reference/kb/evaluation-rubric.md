# 평가 루브릭 (5차원 · 0–10) + 심각도 + 스코어카드

> 내부 규약이다(외부 표준 아님). 점수는 **근거가 뒷받침하는 만큼만** 준다.

## 5차원 0–10 기준
각 차원은 8–10(우수) / 5–7(양호·결함 일부) / 2–4(중대 결함) / 0–1(기능 불가·규약 무시).

| 차원 | 10점 | 감점 트리거 |
|---|---|---|
| **D1 규약 정합** | STANDARD 완전 충족, 경로 무결, 등록 완료 | 프론트매터/`리뷰 훅`/번들 누락, 경로 깨짐, manifest 미등록 |
| **D2 기술 정합성** | 기술 주장 전부 사실, 예시 실제 동작/렌더, 구현이 주장과 일치 | 틀린/환각 주장, 안 도는 예시, 구현이 주장 미달 |
| **D3 범용성** | 금지 토큰 0, 일반 예시, `model` 미하드코딩, 최소 tools | 도메인 토큰, 내부 경로, 과다 권한 |
| **D4 주장정합·결정성** | "항상/결정적" 주장에 절차·타이브레이커 완비 | 과대주장, 미정의 타이브레이커, 약속이 절차 초과 |
| **D5 보안** | 트리아지 후 실탐 0, 권한 최소 | 재현된 실탐(비밀전송·RCE·CVE·숨은지시), 미트리아지 |

## 심각도 표 (결함 분류)
| 심각도 | 의미 | 조치 |
|---|---|---|
| **CRITICAL** | 보안 침해·데이터 손실·자산 완전 미동작 | 머지/설치 차단 |
| **HIGH** | 명확한 기술 오류·과대주장發 오작동·재현된 보안 약점 | 머지 전 수정 |
| **MEDIUM** | 규약 위반·결정성 결함·절차 누락·미확인 가정 지적 | 가능시 수정 |
| **LOW** | 스타일·문구·약한 출처·트리아지된 오탐 | 선택 |

## 캘리브레이션 (principles §5)
- CRITICAL은 보안/데이터/완전미동작 한정.
- 미확인 가정·미트리아지 스캔결과 기반 지적 → **MEDIUM 상한**.
- SkillSpector 점수/심각도는 그대로 옮기지 않는다 → 트리아지 후 재산정.

## 결론 규칙
- **차단**: CRITICAL ≥1, 또는 D2/D5 ≤2.
- **조건부 승인**: HIGH만 존재.
- **승인**: CRITICAL/HIGH 없음.

## 스코어카드 포맷
```
## 평가 대상 — <이름·경로> (기준: STANDARD.md, SkillEvaluator vX/tier/status, SkillSpector vX, 정적/LLM/live)
## 종합: D1 n · D2 n · D3 n · D4 n · D5 n /10 → <승인/조건부/차단> + 사유
## 결함(심각도순): [SEV] 제목 — 근거(파일:라인/finding id/재현) → 영향 → 최소 수정안
## SkillSpector 트리아지: | finding | 분류 | 근거라인 | 실탐/오탐 | 사유 |
## SkillEvaluator 증거: mode · exit · overall_status · report · prerequisite completeness
## 잘된 점 / 적용 우선순위(1..n)
## 검증 범위 고지(정적/LLM, 실행 여부)
```
