# Vulpora v1.1.0 — 보안·미사용 코드 탐색과 실행 경계 보강

날짜: 2026-09-11 · 이전 버전: v1.0.1

보안 위험 분석·수정과 미사용 코드 후보 탐색 스킬을 추가했습니다. 설치·세션 실행의 실패 처리,
경량 작업의 실행 주체, 첫 하네스 제안서 작성과 토큰·비용 검증을 보완했습니다.

## 수정 및 개선

- **보안 분석과 수정:** `security-scan-workflow`가 읽기 전용 검토와 명시적 수정 요청을 구분합니다.
  수정 요청은 소스 변경·격리 회귀 검증·독립 재검토까지 연결하며, 공유 서비스의 삭제·설정 변경과
  비밀값 출력은 금지합니다. 선택 설치 시 필수 `security-auditor`도 설치합니다.
  [PR #13](https://github.com/ch4570/vulpora/pull/13)
- **미사용 코드 탐색:** `explore-dead-code`가 참조를 묶음 검색해 후보·근거·신뢰도를 보고합니다.
  간접 등록과 외부 API는 추가 확인 대상으로 남기며 코드를 삭제하지 않습니다.
  [PR #14](https://github.com/ch4570/vulpora/pull/14)
- **설치·실행 경계:** 잘못된 selector를 변경 전에 거부하고, 마지막 설치 receipt를 제거해도
  작업 기록을 보존합니다. 세션의 편집 대상 사전 검증, timeout 정리와 모호한 평가 결과 거부를
  보강했습니다. [PR #7](https://github.com/ch4570/vulpora/pull/7)
- **DB 조회 보호:** NL-to-SQL의 SQL Server 제어문 우회와 MySQL 시간 제한 설정 실패 후 실행을
  차단하고 과도한 응답의 자원 사용을 제한합니다. 제한을 지원하지 않는 MySQL 호환 서버의 조회는
  거부합니다. 읽기 전용 DB 권한과 실제 엔진 검증을 대체하지 않습니다.
  [PR #13](https://github.com/ch4570/vulpora/pull/13)
- **예약 회수:** 실행 기록 게시 실패 시 실행 전임이 확인된 예약만 회수합니다. 취소 이력으로
  중복 환급을 막고, 게시됐거나 사용량이 불명인 실행의 예약은 유지합니다.
  [PR #15](https://github.com/ch4570/vulpora/pull/15), 이슈 #8
- **경량 실행:** 명시적 lightweight 프로필은 lane 수와 관계없이 주 담당자만 실행합니다.
  자동 standard 위임과 고위험 audit 전환은 유지합니다.
  [PR #16](https://github.com/ch4570/vulpora/pull/16), 이슈 #9
- **첫 하네스 제안서:** `harness-propose`가 Codex·Claude·공존 설치와 호스트 목록을 구분합니다.
  기존 보고서 없이 독립 제안서를 작성하고, 호스트 ID의 namespace를 보존하며 정책 파일을
  임의로 만들지 않습니다. [PR #17](https://github.com/ch4570/vulpora/pull/17), 이슈 #10
- **소스 토큰 예산:** `start-task`의 8개 경로에 필수 참조 coverage와 소스 토큰 상한을 적용하고
  CI에서 검사합니다. 소스 토큰은 실제 공급자 청구량이 아닙니다.
  [PR #18](https://github.com/ch4570/vulpora/pull/18), 이슈 #11
- **workflow 경제성:** 사전 고정 과제·전체 시도 비용 집계·사용 가이드를 추가했습니다. 기존 pilot의
  실패와 불명 사용량을 보존하며, 완료로 인정된 작업이 0건인 결과는 `INCONCLUSIVE`로 남깁니다.
  일반적인 비용 절감이나 품질 우위를 주장하지 않습니다.
  [PR #19](https://github.com/ch4570/vulpora/pull/19), 이슈 #12

## 업데이트

GitHub 태그로 CLI를 설치한 뒤 기존 scope와 selector로 스킬·에이전트를 갱신합니다.
아래 예시는 Codex user scope의 전체 catalog 설치입니다.

```sh
npm install --global 'git+https://github.com/ch4570/vulpora.git#v1.1.0'
vulpora setup --runtime codex --scope user
vulpora doctor --runtime codex --scope user
```

Claude Code 직접 설치는 `--runtime claude-code`를 사용합니다. project 또는 선택 설치는 기존
`--scope`, `--target`, selector를 유지합니다. Claude marketplace plugin은 Claude의 plugin
업데이트 경로를 사용합니다. 갱신 후 Codex는 `$vulpora-init`, Claude Code는 `/vulpora-init`으로
대상 저장소의 관리 지침을 갱신합니다. CLI 설치만으로 기존 스킬·에이전트가 갱신되지는 않습니다.

## 호환성과 검증 범위

- 기존 14개 pack과 28개 agent를 유지하며 skill은 62개에서 64개로 늘었습니다.
  저장소 버전은 `1.1.0.0`, npm 형식 패키지와 Claude plugin 버전은 `1.1.0`입니다.
- #8–#12의 개별 PR은 회귀 검사와 CI를 통과한 뒤 병합했습니다. 새 릴리즈 커밋의 CI 및
  패키지·소스 압축본 검증 결과는 [GitHub Release](https://github.com/ch4570/vulpora/releases/tag/v1.1.0)에 기록합니다.
- `explore-dead-code`의 NVIDIA SkillEvaluator Tier 1은 6/6 통과했습니다. keyless 정적 검사는
  실제 저장소 전체 탐색 품질이나 완전한 보안 검증을 보장하지 않습니다.
- 실제 DB 엔진 통합, live Claude marketplace 설치, 광범위한 모델 품질·청구 비용 비교는
  이번 릴리즈의 검증 범위가 아닙니다. OpenCode 지원은 실험적입니다.
- [운영 평가 신뢰 이슈 #1](https://github.com/ch4570/vulpora/issues/1)은 미해결 상태로 유지합니다.
  독립 runner·서명/신뢰 정책·불변 증거 저장소·공급자 예산 통제의 운영 검증은 완료되지 않았으며,
  자동 승격은 계속 차단합니다. 패키지 배포는 이 운영 신뢰를 인증하지 않습니다.

shasum -a 256 -c SHA256SUMS
