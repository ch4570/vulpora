# Vulpora artwork

[Brand and compatibility guide](../naming.md)

`vulpora-hero.png` is the original README banner for Vulpora: an ivory mythical fox with flowing tails,
an amber constellation, and a dark background. Both language editions use this local asset, so the
README does not depend on an external image host.

Created on 2026-09-07 with the **built-in image generation tool**, then edited with the same tool to
apply the final wordmark and clean the typography. No third-party mascot or logo was supplied.
The final image was visually reviewed and copied here without changing its pixels.

- [Banner](vulpora-hero.png)
- [Generation and final edit prompts](vulpora-prompts.md)

Use the same wordmark, fox motif, and palette when producing additional project materials.
