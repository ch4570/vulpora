# Standard execution

Read this only when the selector returns `standard`. Lightweight work is fully described in
[SKILL.md](../../SKILL.md); audit uses its separate operating contract.

Keep one concise working brief in session context and a short implementation plan. Resolve discoverable facts
before asking; batch currently known material choices into one turn. Do not request confirmation when the user's
implementation intent, repository evidence, and safe defaults already resolve them.

Use one primary owner for coupled changes, including configuration, fixtures, and test resources needed for the
outcome. Multiple files do not establish independent lanes. Delegate only independently executable and verifiable
work when its benefit justifies another session's startup and rereads; small work stays primary-owned.

For actual delegation, read [task/model routing](model-routing.md) and prefer the
[independent-session transport](independent-sessions.md). Send a bounded task capsule and selected paths without
the parent transcript. Apply explicit model/effort routing and shared budget reservation before execution;
deterministic verification uses no model. If the transport is unavailable, keep the task primary-owned or use the
verified native routing path. Never fabricate native child IDs from process or session identifiers.

Inspect the returned diff and command evidence before accepting a worker's result. Resolution and completion
claims do not prove execution or acceptance. Keep transport capsules, local diagnostics, and bounded results local;
return compact results instead of raw events. These records do not require an audit ledger, DAG, or report.

Reclaim understood blockers at the next progress check, no later than 60 seconds without useful progress. An
obvious omitted support file can be reclaimed by the primary without further permission within authorized scope.

Reuse visible child checks that cover the unchanged candidate; run one relevant integration check for combined
work. Do not force duplicate `--rerun` execution without evidence that existing results are insufficient. Apply
the entrypoint's diff and completion checks. If new facts reveal an audit signal, switch before the risky action;
explicit audit work retains its native receipt contract.
