# Typography

## Hierarchy

- Use one document title and ordered heading levels without skipping levels.
- Make body text the baseline; distinguish title, section, subsection, caption, code, and metadata
  through a small consistent type scale.
- Prefer weight and whitespace over excessive color, capitalization, or decorative rules.
- Keep line length comfortable for continuous reading; use narrower measure for prose than for
  tables and code.
- Avoid widowed headings: keep a heading with at least the first meaningful block that follows.

## Language and fonts

- Declare the document language and preserve the source language's punctuation and word-breaking
  conventions.
- Choose a fallback chain that covers all scripts in the document. For Korean, require a local
  CJK-capable sans or serif fallback and verify glyphs in the rendered output.
- Do not download, embed, or license a font implicitly. Record missing font coverage as a
  publisher blocker.

## Accessibility

- Do not encode hierarchy with font size alone; preserve semantic headings and labels.
- Keep essential distinctions visible without color.
- Use descriptive link text, alternative text, and captions that make sense out of visual
  context.
