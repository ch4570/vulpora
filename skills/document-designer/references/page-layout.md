# Page Layout

## Structure

- Lead with the decision, outcome, or purpose, then provide supporting evidence and detail.
- Use a consistent spacing scale between title, section, paragraph, list, table, figure, and code.
- Keep related content together; separate unrelated sections with clear headings and whitespace.
- Use a table of contents for long navigational documents, not short memos.

## Page-aware intent

- Add page-break hints only at stable semantic boundaries. Never insert repeated blank lines to
  force pagination.
- Keep captions with their figures and headings with their first content block.
- Avoid splitting short tables, callouts, or small code blocks across pages when practical.
- Move oversized detail to an appendix before reducing the global font size.
- Balance pages without manufacturing filler. A deliberate short final page is preferable to
  distorted spacing.

## Figures

- Place a figure near its first reference and number it only when cross-references need stable
  identifiers.
- State target width and aspect constraints without rasterizing an editable vector source.
- Require a final render check for page-edge overflow, scaling, caption separation, and
  legibility.
