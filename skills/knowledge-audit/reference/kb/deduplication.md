# KB: 중복 제거와 단일 출처(SSOT)

## 1. ARID / DRY 원칙 (Write the Docs)

Write the Docs "Documentation principles"는 문서에 대해 **ARID(Accept Repetition In Documentation, 약간의 반복 허용)** 를 말하면서도, 같은 **사실(fact)** 이 여러 곳에 흩어지는 것은 경계한다.

- **단일 출처(Single Source of Truth)**: 각 사실은 **한 곳(정본 위치)** 에만 산다. 나머지는 그곳을 **링크**한다.
- **위험**: 같은 사실이 복제되면 한쪽만 갱신돼 **모순(contradiction)** 이 생긴다. 모순된 지식은 없는 것만 못하다.
- ARID는 설명·예시의 약간의 중복은 허용하되, **권위 있는 단정(authoritative claim)** 의 복제는 금지로 읽는다.

## 2. 중복 탐지 (overlap detection)

후보가 기존 정본과 겹치는지 판단하는 신호:

| 신호 | 판단 |
|------|------|
| 같은 파일/심볼/플래그를 다룸 | 강한 중복 의심 |
| 같은 결론을 다른 문장으로 단정 | 중복(병합 대상) |
| 같은 주제의 **하위 집합**(더 구체적) | 병합 또는 정본에 보강 |
| 같은 주제인데 **결론이 다름** | 모순 — 우선 검증으로 진실 판정 |

- 키워드/심볼 기준 `grep`으로 정본 인덱스를 먼저 훑어 후보의 중복 여부를 본다.
- 신규 항목 승급 전에 **반드시 정본 인덱스를 읽어** 중복을 차단한다(전처리 단계의 목적).

## 3. 병합(merge) vs 링크(link) vs 정본 선택

- **병합**: 두 항목이 같은 사실의 부분집합/보완이면 **정본 위치 하나로 합친다.** 더 정확·최신인 쪽을 본문으로, 다른 쪽의 유효 디테일을 흡수.
- **링크**: 다른 주제지만 관련 있으면 복제하지 말고 **정본 위치를 상호 참조**한다.
- **정본 위치(canonical home) 선택 기준**:
  1. 주제의 **본령(本領)** 에 가장 가까운 파일.
  2. 가장 **검증·최신**(`last_verified`)인 항목.
  3. 가장 많이 **참조되는**(다른 항목이 가리키는) 항목.

## 4. 모순(contradiction) 처리

- 두 항목이 **상충하면 둘 다 그대로 두지 않는다.** 코드 실증으로 진실을 판정.
- 참인 쪽을 정본으로, 거짓인 쪽은 폐기. 둘 다 부분적이면 병합.
- 판정 불가면 **둘 다 보류**로 내리고 다음 감사로 미룬다(거짓을 인용시키지 않기 위해).

## 리뷰 훅

- [ ] 승급 전에 **정본 인덱스를 읽어** 중복을 확인했는가.
- [ ] 같은 **사실의 권위 단정**이 두 곳 이상에 복제돼 있지 않은가(SSOT).
- [ ] 겹치는 항목을 **병합/링크**로 정리했는가(무작정 복제 금지).
- [ ] 정본 위치(canonical home)를 **본령·최신·피참조** 기준으로 골랐는가.
- [ ] **모순된 항목**을 방치하지 않고 검증으로 진실 판정했는가.
